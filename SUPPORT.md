# Support

Dashboard Help Badge is community software maintained by Leiter Consulting.

- Use [GitHub Issues](https://github.com/LeiterConsulting/dashboard-help-badge/issues) for reproducible bugs, compatibility reports, and feature requests.
- Use GitHub's private vulnerability-reporting flow for security concerns.
- Include the app version, Splunk version, browser, dashboard theme, relevant visualization type, and minimal reproduction source.

This project is not supported or endorsed by Splunk Inc. Splunk Support cannot troubleshoot this third-party app.
